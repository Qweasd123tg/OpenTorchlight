## Компилятор и оригинальная игра

Закреплённый GCC 4.4.7 находится в ранее переданном архиве в чате. Бинарный архив компилятора в эту ветку не загружен. После его распаковки использовать handoff/env.sh и инструкции AGENTS.md. Оригинальный ELF, игровой runtime и ресурсы в Git не публикуются; нужен внешний вход из собственной копии игры или ранее переданного комплекта.

SHA256 оригинального ELF: 91b41ae9dfea30aab6bc14dbbfcceaee096d600f39635b8507f5a88b5d41724b.

Принятые функции и headless-тесты ещё не доказывают самостоятельную сборку или играбельность всего проекта. Оконный запуск выполнять только по отдельной просьбе пользователя.

Индекс разделён на небольшие CSV-файлы с одинаковыми заголовками. Вместе они содержат все 7668 адресов без повторов и сокращения имён. index.json перечисляет части, количество строк и SHA256. Прежний индекс handoff/SMALL_FUNCTIONS.csv сохранён без изменений только для истории.
