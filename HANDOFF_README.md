# Комплект OpenTorchlight для нового чата

Отдельная ветка передачи, без смешивания с основной работой. Исходники проекта находятся в корне. Проверенная база: дерево PR67 (cb71dd36718de4567796c4882c07903aea3fcf90), включая предыдущие draft PR. Они не объявляются слитыми в main. Более поздняя пачка Equipment сюда не включена.

## Что сохранено

- Полное дерево исходников, заголовков, тестов, инструментов и third_party.
- handoff/recovered-pass10: все 401 C++-определение из пользовательского state.json, отдельные файлы и индекс. Они сохранены без исполнения. Исторически указаны 403 новых адреса; свежая приёмка ещё нужна.
- Исходные state.json и check375.json сохранены в ранее присланном архиве; здесь опубликованы все 401 извлечённые определения и индекс. Полных изменённых заголовков в снимке нет, только их имена.
- Компилятор GCC 4.4.7 предоставлен в ранее присланном архиве в чате. Его загрузка в GitHub не завершилась. Скопировать оттуда каталог toolchain/ в корень этой рабочей копии.
- handoff/SMALL_FUNCTIONS.csv: 409 небольших кандидатов на момент снимка; перед выбором сверить актуальные owners и совпадения с pass10.

## Запуск в новом чате

Скачать ZIP этой ветки или клонировать её в путь без пробелов. Скопировать toolchain/ из переданного архива, затем:

    source handoff/env.sh

Исходный игровой ELF намеренно не публикуется в Git согласно AGENTS.md. Взять inputs/Torchlight.bin.x86_64 из ранее переданного полного архива или собственной копии игры и положить в inputs/ этой рабочей копии. Ожидаемый SHA256:
91b41ae9dfea30aab6bc14dbbfcceaee096d600f39635b8507f5a88b5d41724b

    python3 tools/decomp/toolchain.py setup
    python3 tools/decomp/check.py --no-game

Среда: Linux x86_64, Python 3.10+, Bash и системные утилиты. Полный игровой runtime и ресурсы здесь отсутствуют. Оригинальный ELF не запускать напрямую. Проверенный полный переносимый архив ранее прошёл check.py --no-game: 1421 MATCH, код 0. Это свидетельство базы, не новый результат для 401 импортированного фрагмента.

Прочитать AGENTS.md и decomp/README.md. Крупные функции и dot-owned TU остаются основному исполнителю. Мелкие выбирать только после сверки owners и pass10; не дублировать уже имеющиеся фрагменты. Перед восстановлением получить свежий llm_loop.py --prepare-only --no-autotest --model-retries 0. Не менять критерии приёмки, не подменять владельцев. Возвращать полный diff исходников и заголовков и свежие отчёты, а не только журнал адресов.

Не выполнять присланные скрипты, код и тесты без требуемого отдельного разрешения. 401 фрагмент сохранён как исходный материал, а не автоматически подключён к сборке.
