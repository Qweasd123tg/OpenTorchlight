# Полный текущий снимок OpenTorchlight

Это общий комплект всех наработок, доступных в этой рабочей копии на 10 октября 2026 года. Число 401 относится только к дополнительным определениям из последнего накопительного снимка Pro, а не ко всему проекту.

## Общая база и отсутствие двойной работы

В корне находится полное текущее дерево проекта: main до PR48, последовательные проверенные изменения draft PR49–67 и последняя проверенная пачка Equipment. Сохранены исходники, заголовки, third_party, инструменты, все тесты и накопленные исследования research/. Исходный локальный коммит последней пачки: 431ee937a5d89372fdf6243231de5b247aa5c978. Это отдельная ветка передачи, не слияние draft PR в main.

Последняя независимая полная проверка: 362 теста без ошибок; 1657 принятых игровых адресов, из них 1448 MATCH и 209 по сравнениям поведения. Все ранее принятые адреса сохранены.

Дополнительно handoff/recovered-pass10/ содержит все 401 C++-определение из state.json Pro. Они относятся к 405 уникальным адресам с учётом ABI-вариантов; 2 адресов уже пересекаются с текущей приёмкой. Совместное множество принятой базы и адресов этих фрагментов: 2060 адресов. Это НЕ число новых принятых функций: фрагменты Pro требуют свежей проверки и восстановления недостающих изменений заголовков.

ПЕРЕД выбором задачи читать handoff/function-index/ (CSV по частям). Это общий индекс 6494 адресов из текущего отчёта и Pro: уже принятое, MATCH вне игрового счётчика, имеющиеся DIFF-реализации, фрагменты Pro и работа в процессе. Не переписывать существующее с нуля. Сначала сверить исходник и доказательства; затем decomp/owners.json. SMALL_FUNCTIONS.csv из прежнего снимка является только исторической подсказкой, а не актуальной очередью: общий индекс имеет приоритет.

Крупная getTextEventObject (0xa9ba60) в работе у dot. Незавершённый кандидат сохранён в handoff/in-progress/ отдельно от сборки и не засчитан. Мелкие функции пользователь продолжает отдельно. Другие занятые TU не присваивать.

## Компилятор и исходная игра

Компилятор GCC 4.4.7 пока находится только в ранее переданном архиве в чате: загрузка бинарника в GitHub была отменена и не завершилась. Скопировать оттуда toolchain/ в корень этой копии. Исходный ELF также взять из inputs/ того архива или собственной игры: он не публикуется в Git согласно AGENTS.md. SHA256 ELF: 91b41ae9dfea30aab6bc14dbbfcceaee096d600f39635b8507f5a88b5d41724b.

    source handoff/env.sh
    python3 tools/decomp/toolchain.py setup
    python3 tools/decomp/check.py --no-game

Ветка пока не автономна без этих входов. Среда Linux x86_64, Python 3.10+, Bash. Полный runtime требует дополнительных игровых библиотек и ресурсов. Не запускать ELF напрямую или GUI. Прежние статусы не заменяют свежую проверку в новой среде.

Прочитать AGENTS.md и decomp/README.md. Перед восстановлением подготовить свежий пакет llm_loop.py --prepare-only --no-autotest --model-retries 0. Не менять критерии MATCH, покрытие или чужое владение. Возвращать полные исходники и заголовки, diff и свежие результаты, а не только адреса. Присланные Pro-код, скрипты и тесты здесь не выполнялись.
