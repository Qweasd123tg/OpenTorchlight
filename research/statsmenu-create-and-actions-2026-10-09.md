Original ELF: `91b41ae9dfea30aab6bc14dbbfcceaee096d600f39635b8507f5a88b5d41724b`.
Pinned GCC 4.4.7, C++98, original SDKs; headless checks only. Owner `dot`.

## Restored code

`CStatsMenu::createMenus()` at `0xc14860` restores 15365 original bytes:
model path/extremes/bounds/position/visibility, GUI imageset and root window,
layout lookup/scaling/function mapping, blocker and panels, close callback,
all statistic fields, fame/experience sizes, four UTF-8 tooltip descriptions,
and the eight ordered spend/reclaim subscriptions with multi-click disabled.
The ranged description is at +0xb0 and magic at +0xa8. Fire resistance is +0x150;
these are original positions rather than a guessed sequential ordering.

The following twelve companions are byte-MATCH with full object metadata checks:

- `setOwner` 0xc042b0 (5 bytes), `handle_CloseButton` 0xc042c0 (17),
  `processInput` 0xc042e0 (40), `setOpen` 0xc0b370 (869).
- Reclaim Magic/Defense/Ranged/Melee at 0xc04310/0xc04370/0xc043d0/0xc04430,
  91 bytes each.
- Spend Magic/Defense/Ranged/Melee at 0xc04490/0xc044e0/0xc04530/0xc04580,
  73/73/73/75 bytes.

Two spending callbacks initially differed only in scratch-register allocation.
Ordering their ordinary definitions consistently with the original resolved both;
no register pinning, inline assembly or comparator relaxation was used.

StatsMenu's sound-bank pointer is now explicitly placed at +0x1b8 without changing
layout. Character and GameUI gain only verified non-virtual dependency declarations
and a friend declaration; their game bodies are untouched. The tooltip conversion
uses a caller-local correct std::wstring return declaration, evidenced by the
original hidden result and assign calls. The unrelated legacy autogenerated
namespace declaration/source is not changed in this slice.
