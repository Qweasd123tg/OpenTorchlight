## Контракт

`updatePositionByVelocity(dt: float)` — один шаг движения снаряда.
Всё — `binary32` SSE, порядок операций фиксирован (переносимо побитово).
Константы прочитаны из ELF, не из имён соседних символов objdump:

| `0xfa87a0` | double `1e-8` | eps нормализации (ucomisd+jbe: пропуск, NaN тоже пропускает) |
| `0xfa47fc` | float `1.0` | цель нормализации скорости |
| `0xfa47f8` | float `0.0` | порог таймера arch (`+0x258 > 0`, ja+jp) |

## Фазы (важно: `+0x148/14c/148` — это СКОРОСТЬ, не позиция)

1. **Steer-акселерация** (строки 8–40): кватернион `*0x130` → направление ×
   скорость `+0x154`; `vel += dir·speed·dt` (`+0x150/14c/148` = z/y/x,
   пишется в обратном порядке); второй кватернион `*0x138` → ещё один шаг
   `vel += dir2·speed·dt`. Позиция здесь НЕ интегрируется (это делает
   `update()`/движок); функция — только velocity.
2. **Нормализация** (41–100): `|v|`, пропуск при `|v| <= 1e-8`
   (включая NaN); иначе `v *= 1.0/|v|`.
3. **Перенацеливание** (101–165): `+0x258 -= dt`; если цель `+0x240`
   null — пропуск; если цель мертва (`alive`) — линейный поиск старого
   указателя в массиве `+0x298` (страйд 8, граница `+0x2a0`; вторая граница
   `+0x2a4` ведёт в путь `L0`, мёртвый при инварианте `+0x2a4 >= +0x2a0`, —
   открыто, доказать трейсом); при находке — `getPosition` +
   `getClosestTarget` + `setTarget`.
4. **Arch-гейт** (166–184): если `+0x258 > 0`, `+0x230 != 0`,
   `+0x250 > 0`: аккумулятор `+0x25c += dt`; fired-ветвь — ниже.
5. **Splash** (иначе, 300–313): `+0x278 += dt`; `+0x274 += dt·+0x268`;
   если `+0x278 > +0x270` — jitter-ветвь; иначе clamp lateral (ниже).
6. **Clamp lateral** (314–322, 493–501): если `|+0x274| > |+0x264|`:
   `+0x274 = copysign(+0x264, +0x274)`; дальше steer.
7. **Jitter** (502–515): `+0x274 += randomBetweenVolatile(-+0x26c, +0x26c)`
   (знак через xorps с `-0.0`); `+0x278 = 0`; перепроверка.
8. **Steer/Blend** (193–300): направление на цель (`target + 2·+0x178`
   по Y — «aim up»); нормализация; `vel = dir·+0x250 + vel·(1-+0x250)`
   (порядок mulss/addss зафиксирован построчно); повторная нормализация;
   аккумулятор arch.
9. **Spline** (517–649): `dist = |v|·dt + +0x1c4`, clamp к длине пути
   (`+0x210+0x18`); при превышении — ротация сегментов
   (`+0x1b8→+0x1c0`, `+0x198→+0x1bc`); сэмплы `GetSplinePositionAtDistance`
   в `d` и `d-0.02` → касательная → нормализация; ориентация `*0x128`,
   если `+0x108 != 0`.
10. **Homing lock** (650–679): если дистанция от собственной позиции
    (getPosition) до `+0x1e0/1e4/1e8` > eps:
    точка = pos; `placeSphere()`.
11. **Trails** (457–491): `GetInt(KSETTINGS_SHOW_MISSILE_TRAILS)`
    (`0x150b574`); `!= 1` — возврат; иначе тоже возврат после блока
    (spawn следов — движковый вызов, не переносится; сам флаг — открытый
    вход настроек).

## Карта полей CMissile (смещения — original-code; имена — рабочие)

`+0x148/14c/150` velocity xyz (+0x150=z, +0x14c=y, +0x148=x); `+0x154` speed; `+0x258` homing-таймер; `+0x240`
цель; `+0x298/2a0/2a4` массив целей/границы; `+0x250` arch-фактор;
`+0x25c` arch-аккумулятор; `+0x230` arch-объект; `+0x270/274/278`
splash (интервал/lateral/таймер); `+0x268/264/26c` splash-rate/cap/jitter;
`+0x210` путь; `+0x1c4` дистанция; `+0x1b8/1c0/198/1bc` сегменты;
`+0x108` orient-объект; `+0x1e0/1e4/1e8` lock-точка; `+0x178` aim-up;
`+0x15c` steer-rate; `+0x19c` spline-порог.

## Открытое (не выдумывать)

- Виртуалы `*0x130/*0x138` (кватернионы), `*0x128` (ориентация по
  направлению), `*0xf0` (кватернион для getClosestTarget): смещения и
  наблюдаемые сигнатуры зафиксированы, цели — по vtable (символа
  `_ZTV8CMissile` в списке нет; нужен RTTI-трейс или Ghidra).
- `CPath::GetSplinePositionAtDistance @0xc879e0` — отдельный перенос
  (чистая математика, следующий кандидат).
- `MATH::rotateY @0xc7a400` — сверить с `yaw_rotation` порта.
- `randomBetweenVolatile` — сверить с volatile-RNG порта.
- `KSETTINGS_SHOW_MISSILE_TRAILS` в рантайме; инвариант `+0x2a4>=+0x2a0`.
- `placeSphere`, spawn следов, `setTarget` сайд-эффекты — движковые стоки.
