# Единый комплект аудита OpenTorchlight

Главный документ — **FULL_AUDIT_RU.md**. Он объединяет выводы о действующем конвейере, новые измерения и решения по всем прежним предложениям. Для внедрения без чтения переписки используется **IMPLEMENTATION_SPEC_RU.txt**.

Это аудит и набор проверок, не готовый универсальный декомпилятор. Оригинальный проект не изменён. Новых принятых игровых функций в этом запуске нет.

## Состав

- `results/` — новая инвентаризация, зависимости заголовков, распределение крупных функций, граф вызовов, хеши исходников и реальные журналы проверок.
- `tools/` — два запускаемых средства проверки и тесты инвентаризатора.
- `patches/` — три совместно проверенных прежних патча: индексирование objdiff, сохранение cv-квалификаторов, изоляция/повтор экспорта Ghidra. Они не исправляют все ограничения приёмки из отчёта.
- `references/previous-audits/` — все девять предыдущих ZIP с исходными прототипами. Они сохранены как свидетельства и материалы для реализации; все их эксперименты заново не запускались.

## Повторить инвентаризацию

Требуется Python 3.10+ и распакованный исходный архив. Команды выполняются из корня этого комплекта. Путь вывода должен находиться вне каталога исходного проекта.

```bash
python3 tools/audit_snapshot.py "/путь/к/OpenTorchlight-main" --out /tmp/otl-audit
python3 -m unittest discover -s tools -p 'test_*.py' -v
```

Инвентаризатор не вызывает модели, компилятор, Ghidra или игру. Граф includes лексический: он не исполняет препроцессор и не доказывает использование всех включённых классов. Исторические результаты не превращаются в текущую очередь незавершённых функций.

## Проверить совместимость патчей

Требуются Python и `git`. Изменения применяются только во временной копии; исходный проект не правится.

```bash
python3 tools/verify_patch_bundle.py "/путь/к/OpenTorchlight-main" \
    --out /tmp/otl-patch-check
```

Скрипт запускает реальные Python-тесты проекта и файловые регрессии экспортёра. Последние используют управляемую модель файлового обмена вместо Ghidra. Он не запускает игру и не вызывает модель. При любой ошибке тестов возвращается ненулевой код; журнал сохраняется.

В этой среде обычный и временно исправленный проекты дали одинаковый результат: 24 теста прошли, 2 завершились ошибкой отсутствующего GCC 4.4.7. Это не полный PASS. Все 16 отдельных регрессий экспортёра и 8 тестов нового инвентаризатора прошли. Java-патч внутри настоящей Ghidra не проверен.

Не накладывайте патчи на актуальную рабочую ветку вслепую: часть исправлений уже могла быть внедрена. Тест временной копии не заменяет сравнение с оригинальным ELF и регрессионные проверки текущей ветки.

## Проверка границ

В присланном дереве нет оригинального ELF/PE, внешнего целевого компилятора и базы Ghidra. Поэтому полный `check`, массовая новая декомпиляция и сборка игры здесь не выполнены. Хеши всех 2 285 исходных файлов сохранены в `results/source_manifest.json`; проверка отсутствия изменений — `results/source_integrity.json`.

Действующая в проекте последняя запись README — 482/5 247 функций, 122 964 байта, 81 тест PASS — историческая. Не используйте её как сегодняшнюю метрику своего рабочего компьютера.
