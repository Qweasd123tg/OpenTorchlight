# OpenTorchlight pass 9

Сначала прочитайте `REPORT_RU.md`. Это исследовательский пакет: исходный проект не изменён, Ghidra и игра не запускались.

Проверить приложенный патч в отдельной временной копии:

```bash
python3 run_checks.py /путь/к/OpenTorchlight-main --out /tmp/ot-pass9-check
```

Дополнительно повторить измерение PCH системным `g++`:

```bash
python3 run_checks.py /путь/к/OpenTorchlight-main --out /tmp/ot-pass9-check --benchmark
```

Команда не применяет патч к репозиторию. Она останавливается при несовместимости версии файлов. Инструкции опционального применения находятся в отчёте.

`patches/` — изменения Python-обвязки и Java-аргумента тайм-аута.
`preview/` — результат применения патча к присланному срезу, для чтения.
`scripts/` — воспроизводимые проверки и измерение; `make_patch.py` предназначен только для сохранённого исходного среза.
`results/` — исходные результаты, временные измерения и контрольные суммы.

Пределы проверки: реальные Python-утилиты с заменённым backend Ghidra; реальные C++-файлы с GCC 14.2. Не проверены оригинальный GCC 4.4.7, оригинальный ELF, Ghidra-проект и вся игра. Общий коэффициент ускорения неизвестен, новых принятых игровых функций нет.
