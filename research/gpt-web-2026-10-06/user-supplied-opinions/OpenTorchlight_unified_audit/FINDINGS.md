# Каталог замечаний и дополнений



P0 — надёжность приёмки/данных. P1 — ближайшее полезное внедрение. P2 — ограниченный пилот или отложенное исследование. Это порядок, не оценка часов.



## A01 · Нулевой выбор тестов возвращает успех

**Этап:** Приёмка. **Приоритет:** P0. **Основание:** Воспроизведено на реальном коде.

**Где:** `decomp/hybrid/loader.c:run_tests; tools/decomp/hybrid.py:selftest`.

Нативный loader с двумя синтетическими тестами: несуществующий фильтр выполняет 0 тестов, возвращает 0 и печатает 2 tests. selftest наследует фильтр окружения.

**Действие:** Считать реально выполненные тесты; ноль — ошибка. Полную приёмку запускать без ambient filter. Узкий патч приложен.

**Материал:** `results/new-boundaries/boundary-probes.json`.



## A02 · Провал процесса не запрещает принятие кандидата

**Этап:** Приёмка. **Приоритет:** P0. **Основание:** Воспроизведено на реальном коде.

**Где:** `tools/decomp/llm_loop.py:Loop.test`.

При коде завершения 97 и положительных строках stats реальная Loop.test принимает кандидат. Воспроизведение подставляет внешний process report, не запускает игру.

**Действие:** Требовать успешный код процесса до принятия любых stats. Узкий патч приложен.

**Материал:** `results/new-boundaries/boundary-probes.json`.



## A03 · Старый mutation report привязывается к текущему коду

**Этап:** Приёмка. **Приоритет:** P0. **Основание:** Воспроизведено на реальном коде.

**Где:** `tools/decomp/mutate.py:record`.

record получает текущий code_digest и присоединяет его к ранее сохранённой статистике, которая не содержит baseline fingerprint.

**Действие:** Сохранять baseline при испытании; при record проверять идентичность исходников, объекта, теста, зависимостей, окружения. Старую статистику без baseline считать исторической.

**Материал:** `results/new-boundaries/boundary-probes.json`.



## A04 · Объявление оригинала считается покрытием

## A05 · Отвергнутый кандидат виден в рабочем src

**Этап:** Публикация. **Приоритет:** P0. **Основание:** Воспроизведено на реальном коде.

**Где:** `tools/decomp/llm_loop.py:Loop.test`.

**Действие:** Весь эксперимент выполнять в staging TU. Публиковать исходник и заголовки атомарно после проверки. Не утверждается, что нормально завершённый loop всегда оставляет отвергнутый код.

## A06 · Promotion сравнивает статус, а не проверенную реализацию
