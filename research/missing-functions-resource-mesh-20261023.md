## Существенное поведение

Регистрация модели проверяет существование файла перед поиском в кеше,
нормализует путь и синхронно обновляет таблицы имя→ID и ID→имя. Фикстура
использует настоящий FileSystem/EditorScene и файлы; наблюдаемая граница
дополнительно меняет кеш во время getFileInfo.

Mesh-функции сохраняют общий/отдельный vertex data, смещения вершин,
исходные нормали, необязательные UV, строку `nocollide`, назначения костей
и порядок материалов. В оригинальной Linux сборке IT_32BIT читается через
8-байтный unsigned long; это намеренно сохранено. Для этой ветви тест создаёт
настоящий IT_32BIT buffer с достаточной физической ёмкостью. Неопределённые
неинициализированные хвосты новых массивов не выдаются за совпадение; для
realloc-ветви сохранение предварительно заполненных UV проверяется отдельно.

У pinned SDK отсутствовало поле Runic Mesh::mMaxBoneAssignments между
mSubMeshList и mFreshFromDisk. Getter библиотеки по 0x1d8230 читает ushort
по 0x90, C1 его обнуляет; sharedVertexData в библиотеке и ELF находится по
0x1f0. Проектный OgreMesh.h — копия закреплённого SDK с этим полем, без
изменения общего cache. Новые fixtures включают его перед Ogre.h, поскольку
вложенные quoted-includes SDK иначе выбирают SDK-файл рядом с собой.

Collision loader проверяется реальным экспортом и чтением синтетических
MEDIA/*.mesh через OGRE. Проверяются повторное имя, отсутствующий файл,
замена прежнего collision list, обратный порядок индексов граней, normals,
face bounds и удаление mesh из менеджера. Пустой submesh без index buffer и
пути вне ожидаемой MEDIA-структуры приводят к сбою самого оригинала и не
используются как доказательства PASS; неудачные диагностические запуски сохранены.

Missile preloader использует настоящие native Editor, Layout, Descriptor,
CMissile, Scene и временные UTF16 .layout. Фикстура проверяет реальную загрузку
и отдельно границу загрузчика с дублями имён, uppercase, NULL/RTTI,
отсоединением объектов и временем жизни. Reader оригинала падает на пути без
расширения; это не засчитывалось завершённым сравнением.
