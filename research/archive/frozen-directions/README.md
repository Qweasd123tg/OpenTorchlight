# Архив замороженных направлений

С 3 октября 2026 рабочий процесс — [decomp](../../../decomp/README.md).
Этот каталог хранит историю прежнего порта `src/`, code-first и p-code.
Указания «текущий», «следующий», «действует», стадии и численные результаты
внутри архивных текстов относятся к их прежним снимкам. Из них не назначают
новую работу и не принимают функции decomp.

Сюда перенесены:

- [Длинный прежний README](README-remake.md), результаты large-этапов и ревью
  пакетов: исторические изменения порта и ограничения их проверки.
- [NEXT_CHECKS.md](NEXT_CHECKS.md),
  [FULL_GAME_ROADMAP_RU.md](FULL_GAME_ROADMAP_RU.md), планы large-15/16
  и [PORTING.md](PORTING.md): прежние очереди и требования.
- [code-first.md](code-first.md), [codefirst-tooling.md](codefirst-tooling.md),
  scripted-automation, scripted-packets, menu-preparation-automation:
  инструкции замороженного процесса.
- Donor triage, auto-triage и remaining-work-inventory: старые сводки,
  которые не описывают текущую готовность.

Формулы, адреса, разобранные ветви и границы экспериментов можно использовать
как подсказки, перепроверив их по оригиналу. Успех теста старого собственного
runtime не переносится на восстановленный исходник оригинальной игры.

Пять файлов старых рабочих/ролевых промптов удалены: в них нет самостоятельных
сведений о поведении оригинала. При необходимости исходные тексты доступны
в git на `5e23b28`: `research/fast-work-prompt.md`, `research/codefirst/`.

`CHECKSUMS.sha256` — сохранённый манифест прежнего входного пакета с его
исходными путями, не контрольные суммы текущего дерева или этих перенесённых
текстов. Архивные документы дополнены предупреждением, ссылки перебазированы.
Оригинальные версии также доступны в истории git.

При очистке 7 октября проверен прежний `registry_sync`: он уже не проходит
на `5e23b28` из-за устаревших отпечатков. После переноса документов набор
его ошибок остался прежним. Старые доказательные входы сохранены без правок;
их реестр не является текущей приёмкой decomp.
