Steam stats, эффекты, разрушаемые объекты, персонажи, монстры, игрок,

Общие заголовки уточняют проверенные раскладки и сигнатуры, включая

Проверки полноты пакета и привязка приёмки к точным входам сохранены.

## Проверки

Полный `tools/decomp/check.py`: **1924 теста, 0 ошибок**. Входы и дерево
исходников не изменялись во время проверки. Новый принятый набор содержит
старый целиком. Runtime, инструменты, заголовки и все production TU проверены
в одном снимке.

Перед повторным общим прогоном исправлены ошибки оснастки:

- SDL перехватывает original и linked адреса обоих методов GameClient;
  все 486 сравнительных пар завершаются.
- Деструктор меню перехватывает фактически вызываемый Ogre allocator и
  проверяет число освобождений.
- Collision subset ссылается на существующие грани; пустой mesh получает
  пустой subset. Все 9 × 48 случаев сохранены.
- Камера получает корректное соотношение count/capacity при проверке роста
  массива. Все 864 случая и отрицательные контроли сохранены.
- Окружение Game заимствует существующий Ogre Root с отдельным учётом
  владения; disabled audio создаётся настоящим native C1 и получает NULL
  для двух не приобретённых FMOD groups перед настоящим D1.

Адресный прогон исправлений: 7 тестов, 0 ошибок. Аварийные завершения и
unwind-вызовы по-прежнему не дают completed-call credit. Дополнительная
проверка 45 новых тестовых файлов и `ResourceEffectQueriesTest.cpp` не
нашла принудительного completed после исключений.

Самотест общего прогона занял **1695.313 секунды** с шестью рабочими
процессами и 60 shards. Использованная команда:

```sh
OTL_JOBS=2 OTL_BUILD_JOBS=2 OTL_SELFTEST_JOBS=6 \
OTL_SELFTEST_SHARDS=60 OTL_SELFTEST_TIMEOUT=1800 \
python3 tools/decomp/check.py
```

На этой машине общий пул допускает два компилятора и шесть headless
процессов. Предыдущий запуск с двумя workers и двумя shards достиг
таймаута 6800 секунд, завершив 1588 тестов. Повтор выполнен после ремонта
fixtures; эти числа описывают два запуска и не являются парным benchmark.

## Сохранённые наработки

Оставшиеся кандидаты из передачи сохранены отдельно от принятого исходника
в локальном проверенном архиве. В этот результат они не включены.
В частности, queued Sound.initialize заблокирован после обнаружения
196 пойманных исключений, ошибочно записанных как завершённые вызовы;
исправленный normal-only fixture ещё требует прогона. FLTK source-library
эксперимент и меню без runtime-проверки также не получают зачёт.

Проверка headless завершается до оригинального `main`. Она не доказывает
играбельность гибрида; живой запуск игры в этой работе не выполнялся.
