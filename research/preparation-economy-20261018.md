# Экономия подготовки decomp

База: `5ee16608a720ee035e867c54c00e2a6ed14a3675` (PR #134).
Изменены инструменты подготовки и инструкции; игровые исходники, заголовки,
сравнительные фикстуры и условия приёмки не менялись.

Применён ранее проверенный [патч контекста](deepen-20261018/context-proposal.patch):
четыре точных weak-специализации `TArrayList::add` для `CSkill*`, `CDataGroup*`,
`int` и `bool`. Сохраняются проверки DB, реального ELF, символа, размера,
сигнатуры, хеша и свежести заголовка, полного объявления pointee. Для `int` и
`bool` устранена только лишняя зависимость от строкового runtime.

Проверка полного реального ASM до/после подтвердила семь разблокированных
контекстов: SkillManager `0xcd3fd0`, `0xcd45c0`, `0xcd4930`; soundbank
`0xa698a0`; UnitResourceList `0xe7eb00`; SpawnClassData `0xa768c0`, `0xa7e170`.
Четыре прежние блокировки деструкторов остались прежними. Это готовность
контекста для восстановления, не приёмка новых игровых функций.

`llm_loop.py --prepare-only --json` выдаёт одним JSON путь `result.json` и его
сохранённый `external_handoff`; журнал направляется в stderr. Дополнительного
сбора контекста или хешей нет. Ready означает только готовность пакета,
blockers сохраняются; нулевой exit status не заменяет их проверку. Публикация
и модельный запуск с этим флагом запрещены. Корневой AGENTS.md теперь сразу
использует этот режим. Общие заголовки/tools завершаются до подготовки пачки,
полная приёмка выполняется один раз после её интеграции, перед коммитом.

Проверки:

- 1001 тест инструментов PASS за 37.589 с, включая 193 проверки контекста и
  четыре новых проверки JSON CLI. Повторного полного прогона не было.
- Реальный prepare SkillManager `0xcd3fd0`: ready, stdout 2252 байта;
  handoff совпал с сохранённым, SHA256 prompt/checkpoint/stage проверены.
  Модель, игра и публикация при подготовке не запускались.
- `python3 tools/decomp/check.py`: 1674 теста, 0 ошибок, 1699.80 с.
  Снимок decomp/tools и input manifest не изменились во время проверки.
  Digest: `39fb7d3bb0d727491e3575763820f48281021004a82327e913ae3595679e47e2`.
- Сохранены все 4210 / 5247 принятых игровых функций: 2779 MATCH и 1431 по
  самотесту. Принятых адресов не прибавилось и не убыло; 814 compiler-generated
  MATCH по-прежнему считаются отдельно.

Сокращены ручные переходы между подготовкой и чтением её результатов.
Процент экономии токенов и ускорение всего самотеста не измерены и не заявлены.
