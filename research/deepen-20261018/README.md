# Исходные игровые методы и стоимость приёмки

База: `c3b2651` (PR #133). Восстановлено и принято ещё **93 функций**: **4210 / 5247 (80.24%)**. MATCH: 2779, поведенческое сравнение: 1431. Compiler static init/dtor: 814, отдельно от игрового счётчика. Принято 2008566 из 3702188 исходных байт.

Изменены 32 исходных TU: редактор и данные, умения и эффекты, спавнеры, карта, звук и ресурсы. 83 заданных адреса прошли приёмку; остальные новые адреса получили естественный MATCH при дополнении полных TU. Источники прежних семи MATCH-методов не изменялись, но GCC поменял их кодогенерацию. Для каждого выполнено новое адресное сравнение с оригиналом; они честно учтены как behavioral. Все 4117 прежних принятых адресов сохранены.

Адресный объединённый прогон: 115 тестов, 13936 нормальных пар, 0 ошибок, 47.501 с. Единственный полный `python3 tools/decomp/check.py`: **1674 тестов, 0 ошибок**, 1665.011 с (27.75 мин). Входы и дерево стабильны; behavioral receipts соответствуют конечным объектам и входам. Неизвестных ссылок и compiler-kind hooks нет. Отдельный предварительный проход компиляции старых фикстур исключён: те же файлы собираются обязательной полной приёмкой.

В `MerchantMainSlotTest`, `MerchantMenuSlotTest`, `InventorySlotTest` четырнадцать одинаковых перехватов перенесены из каждого дочернего процесса в родительский RAII Set. Все случаи, отдельные fork и сравнения сохранены. Пилот OLD/NEW/OLD/NEW: 64.7425 → 55.079 с в среднем, **−14.93%**, по 25992 полные пары в каждом запуске. Inventory: 34.178 → 28.513 с (**−16.57%**, 12996 пар); Merchant pet: 33.352 → 28.212 с (**−15.41%**, 12960 пар). Ошибок/неполных пар нет. Отдельно проверены восстановление detour при обычном выходе и частичной ошибке, наследование дочерним процессом и изоляция arena. Проценты относятся к этим фикстурам; общего ускорения на 15% не заявляем.

Ревью поймало перечитывание ссылки в UnitSpawner после BroadcastEvent: оригинал использует изменённый callback-ом слот, прежний кандидат сохранял старую ссылку. Новый регрессионный случай сначала дал completed mismatch, после исправления — 288 пар без расхождений. Также устранены четыре корреляции входов в новых тестах: замена совпадающего эффекта, отказ требований оружия, оставшийся одноимённый навык того же уровня и fallback позиции при смерти. Результаты полного прогона включают исправленные фикстуры.

Для одно-TU продолжений уже существует `candidate.py --cycle-spec` с сохраняемыми этапами и короткой сводкой. Его следует использовать там, где подходит этот режим, без добавления отдельных полных прогонов на каждый TU общей пачки. Ручные ready-манифесты в этом проходе имели разные форматы; это потребовало адаптеров и привело к повторному подключению AutoTestRuntime при первой объединённой сборке. Служебный файл исключён, адресный прогон повторён успешно до запуска полного. Общий формат передачи исходников/фикстур и исключение generated support — следующий небольшой кандидат сокращения действий, без нового общего раннера. Общие заголовки уточняются до подготовки заданий, затем фиксируются. В этом проходе удалено неподтверждённое void-объявление showWeapon, после чего все 83 выбранных адреса получили свежие пакеты, а объекты 32 кандидатов перепроверены без изменений. Узкий кандидат [context-proposal.patch](context-proposal.patch) расширяет распознавание четырёх конкретных weak add-методов без ослабления проверок. В отдельной копии инструмента 193 теста PASS; на реальном ASM контекст разблокирован для 7 из 11 исследованных адресов, четыре деструктора остались заблокированы. Патч сохранён без строк контекста (`git apply --unidiff-zero`), исходный хеш инструмента и хеш результата указаны в JSON. Патч не применён к работающему инструменту и не даёт приёмки игровых функций; он сохранён для применения до подготовки следующей пачки. Численного выигрыша токенов для этих изменений процесса пока нет. Полный проход относительно предыдущего вырос с 1363.38 до 1665.01 с: новый набор содержит на 88 тестов больше, изменились общие заголовки и условия нагрузки. Самотест вырос с 1271.07 до 1474.73 с, медиана общих тестов длительнее 5 с — на 5.13%; причинность нагрузки/кодогенерации не установлена. Хвост последнего процесса составил 61.86 с, но шесть слотов заняты в среднем на 95.61%, поэтому очереди не объявляются основной причиной. Сырые сопоставления и наибольшие изменения времени сохранены в JSON для адресного следующего измерения, без повторного полного прогона.

Резервы и доказательства перечислены в JSON: неизвестные типы возврата, private-доступы, непрописанные зависимости и отличия SDK. Оконный запуск и самостоятельная игра не проверялись; headless-приёмка функций не доказывает полную играбельность гибрида.
