# Перенос от кода: процесс code-first

Статус: действующий процесс. Заменяет подход «выбрать механику и сделать
похожей» на «взять оригинальную функцию целиком и учесть каждое её действие».

## Единица работы

Единица задания — оригинальная функция целиком, например
`CInventoryMenu::setOpen @0xb4eb70`, а не «сделай открытие инвентаря».
Внутри функции проходятся последовательно все участки: проверки, ранние
выходы, ветви, изменения полей, вызовы, обработка ошибок, завершение.
Обнаружить запуск анимации `OPEN` — не значит восстановить открытие.

Декомпиляция Ghidra — навигация, а не исходник: сомнительные места
сверяются с машинными инструкциями, типы и сигнатуры не закрепляются
преждевременно (иначе ошибка расползётся по программе).

## Реестр — обязательная основа

`research/coverage.tsv` + `research/coverage-summary.json` (из
`research/coverage-boundaries.json` через `tools/coverage_map.py`) — это
реестр работы, а не показатель готовности. Найденный дрейф:
`CGameUI::convertToScreenScale @0xa83ed0` был реализован в
`src/ui_screen_scale.cpp` / `src/ui_layout.cpp`, но числился `unseen`.
Исправлено честной границей `partial` (только арифметика + порядок;
CEGUI-уведомления, рендер и полный `rescaleUI` открыты).

`tests/registry_sync_test.py` (через `tools/audit_registry_sync.py`)
держит реестр синхронным: свежий `coverage.tsv`, валидный
`research/function-transfer.json`, граница для каждой transfer-активной
функции. Полный список несвязанных входов функций печатается как
burn-down; эскалация до жёсткого запрета — по мере закрытия пакетов.

## Четыре стадии вместо одной отметки

`research/function-transfer.json`, ELF SHA-256
`91b41ae9dfea30aab6bc14dbbfcceaee096d600f39635b8507f5a88b5d41724b`:

- **разобрана** — ветви и действия учтены, неизвестные места перечислены;
- **перенесена** — действиям сопоставлен код проекта;
- **подключена** — настоящий вызывающий путь передаёт данные и использует
  результат;
- **сравнена** — указано, что проверено против оригинала и на каких случаях.

Прочитать ≠ перенести ≠ подключить ≠ сравнить. Связь может быть
«несколько оригинальных методов — один общий помощник», но она обязана
оставаться прослеживаемой.

## Места вызовов, а не множество зависимостей

`research/original-callgraph.tsv` хранит только множество вызываемых
функций: `A→B→A` и `B→A` в нём неразличимы. Новый экспорт
`tools/ghidra/ExportCallSites.java` +
`tools/ghidra/export_call_sites.sh` пишет
`research/original-callsites.tsv`: caller, **callsite address**, callee,
мнемоника — порядок, повторы и множественность сохраняются. Условия ветвей
и виртуальные цели разрешаются пофункционно из дизассемблирования и таблиц
виртуальных методов, в TSV их нет по построению.

## Пакет на функцию

`tools/function_package.py --address 0x...` собирает: строку реестра,
стадии переноса, рёбра графа, места вызовов (или явное предупреждение об
их отсутствии), попадания в декомпиляции/дизассемблировании, ссылки порта,
следующий шаг. Дешёвой модели — подготовка пакетов и поиск ссылок.
Названия полей, смысл ветвей и отметки соответствия она не придумывает.
Роли для делегирования: `research/codefirst/prompts/` (исследователь,
портировщик, ревьюер-интегратор). Готовые внешние пакеты (ASM-тела,
callsites) живут вне репозитория как read-only входы; в `research/`
попадают только перепроверенные по ELF срезы. Детали приёмки набора:
`research/codefirst/README.md`.

## Общие данные вместе с функциями

Методы, меняющие одно поле объекта, получают одну согласованную трактовку
поля (типы, начальные значения, места изменения). Связанные методы идут
одним пакетом (`setOpen` + `createMenus` + `update` для меню).

## UI-контур

`research/ui-contour.json`: создание, загрузка ресурсов, ресайз,
обновление, отрисовка, ввод, открытие/закрытие окон. Внутри контура идём по
оригинальным методам и зависимостям, не перескакивая на геймплей. CEGUI
0.6.2 / OGRE 1.6.5 — фиксированная граница, не переписывается.

Первый пакет: семейство масштаба `0xa83ed0/0xa83e70/0xa83ea0` (граница
есть) → `CInventoryMenu::setOpen @0xb4eb70` +
`CInventoryMenu::createMenus @0xb569e0` одним связным пакетом с общей
картой полей. Готовый пакет проверки: `python3
tools/function_package.py --address 0xb4eb70`.
