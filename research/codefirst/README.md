# Ролевые промпты и внешние пакеты

## Промпты (prompts/)

Три ролевых промпта для делегирования code-first работы дешёвой модели:
исследователь (пакеты доказательств), портировщик (реализация по контракту),
ревьюер-интегратор (приёмка по caller/context/order/lifetime).

Происхождение: внешний набор `OpenTorchlight-codefirst-toolkit.zip`
(получен 2026-09-18, лежит вне репозитория рядом с ELF/pak как read-only вход).
При первоначальной приёмке заменены ссылки на отсутствующие файлы.
Теперь промпты согласованы с [действующим процессом](../code-first.md):
целая функция — единица учёта, связанное семейство/производственная цепочка — единица
выполнения, legacy-стадии среза отделены от полного закрытия.
Контракт локальных инструментов — [codefirst-tooling.md](../codefirst-tooling.md).
Файлы внешнего набора не требуются для создания нового локального пакета.

## Готовые пакеты (вне репозитория)

`ready-packets/` набора (inventory-lifecycle, panel-open-family,
ui-scale-contract) в репозиторий НЕ копируются. Проверено при приёмке:

- ASM-тела побайтово совпадают с pinned ELF SHA-256
  `91b41ae9dfea30aab6bc14dbbfcceaee096d600f39635b8507f5a88b5d41724b`
  (полное сравнение `setOpen @0xb4eb70`, точечное `CMerchantMenu::setOpen`);
- все 44 файла пакетов сошлись с `payload_sha256` их манифестов;
- `callsites.json` — места вызовов И переходов из ASM с явными варнингами
  (порядок адресов ≠ порядок исполнения), полезен как дополнение к
  `research/original-callsites.tsv` (при первоначальной приёмке локальный
  индекс отсутствовал; его текущее наличие проверяется отдельно).

При использовании внешнего пакета извлечь его тела из набора, перепроверить
по ELF как выше и только потом сохранять принятые срезы в `research/disassembly/`.
Локальный пакет семейства генерируется в ignored build-каталог или `/tmp`;
его `ENTRY.md`, представители и member deltas — навигация для ревью, не
доказательство эквивалентности. В `research/` принимаются результаты ревью,
а не автоматически сгенерированные отчёты.

Текущий scope по умолчанию — `research/ui-contour.json`; активная цепочка —
MAIN/ENTRY MENU, [контроллер и painter](../mainmenu-controller-painter.md). Общий механизм
проверяется минимум на двух представителях и всех различиях участников;
библиотеки учитываются как закреплённая версия плюс подтверждённые отличия.
Каждый эффект требует настоящего потребителя, установленного по коду.
Полное закрытие принимается по ревью всех блоков ASM, библиотечных контрактов,
производственных вызовов и полей. Сборка и узкие проверки закрепляют перевод;
оригинальный стенд или трасса отвечают на конкретный нерешённый вопрос.
UI-клики, кадры и сквозные сценарии выполняются отдельной явно запрошенной задачей.
Структурный gate проверяет формат и актуальность свидетельств, а не их смысл.
