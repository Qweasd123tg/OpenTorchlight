# OpenTorchlight: восстановление исходника

Цель — чистый исходник первой Torchlight на C++98, который оригинальный
GCC 4.4.7-3.el6 собирает с теми же TU, классами, раскладками и функциями.
Android и сенсорное управление — следующий этап из этого же исходника.

Рабочий процесс — [decomp](decomp/README.md), правила — [AGENTS.md](AGENTS.md).
Исходники находятся в `decomp/src/`, заголовки — в `decomp/include/`,
инструменты — в `tools/decomp/`.

```sh
python3 tools/decomp/toolchain.py setup
python3 tools/decomp/check.py
```

Оригинальный ELF и ресурсы — внешние входы только для чтения, в git не входят.
Функция принимается через строгий MATCH либо выполненное дифференциальное
сравнение с оригиналом, покрывающее её ветви. Процент DIFF и объявления тестов
не доказывают перенос.

На проверенном срезе **7 октября 2026**: 895 строгих MATCH из 5247 игровых
функций; 103 самотеста прошли. Эти числа не являются процентом готовности игры.
Самостоятельная сборка игры ещё не замкнута; гибрид использует оригинальный
процесс и его зависимости. Свежий результат получает `check.py`.

Ремонт инструментов и его ограничения:
[IMPLEMENTED_RU.md](research/gpt-web-2026-10-06/IMPLEMENTED_RU.md).
Навигация по находкам оригинала: [research](research/README.md).

Прежний порт `src/`, code-first и p-code лифтинг заморожены. Их планы,
инструкции и отчёты убраны из рабочего входа в
[исторический архив](research/archive/frozen-directions/README.md).
