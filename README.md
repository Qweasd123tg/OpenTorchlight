# Torchlight: восстановление исходного кода

Сначала восстанавливается совместимая ПК-версия первой Torchlight. После
рабочего вертикального среза тот же переносимый код будет собран для OnePlus 7
с Android 16 и получит сенсорное управление. Требования и исходные находки:
[PORTING.md](PORTING.md).

## Что уже работает

- Переносимая библиотека C++17 с восстановленными `InputState`, `KeyManager`,
  `MouseManager` и логикой движения к указанной точке.
- Сравнение поведения 24 функций с оригинальным Linux-бинарником,
  включая короткие нажатия, удержание, отпускание, двойные клики,
  колесо, координаты и ограничение частоты прокладки пути.
- Чтение оригинального `pak.zip` напрямую с проверкой CRC; подтверждены все
  24 876 записей и оба используемых метода сжатия.
- Типизированный парсер бинарных `.adm`; проверено 15 305 групп и 144 817
  свойств трёх основных игровых таблиц.
- Индекс 3 343 игровых ресурсов по GUID: 2 959 предметов, 295 монстров,
  4 игрока и 85 объектов. Все пути проверены по содержимому `pak.zip`.
- Загрузка всех 3 343 определений `UNIT` с точным наследованием через
  `BASEFILE`; найдено 3 463 уникальных файла, максимальная цепочка — 4.
- Каталог 19 наборов окружения с 1 619 деталями уровня и загрузчик цепочки
  `DUNGEON -> LEVEL -> LAYOUT`. Для города прочитаны все 733 объекта,
  включая 352 детали окружения и 44 размещённых существа.
- Общий разбор правил охватывает все 35 этажей основной кампании: 25 уникальных
  ruleset, 306 типов chunks, 419 точек соединения и 257 допустимых раскладок.
  Он учитывает входы, выходы, обязательные комнаты и списки разрешённых файлов.
- Общий генератор собирает связные случайные этажи из этих фрагментов,
  соблюдает лимиты появления и обязательный выход, сохраняет пары дверей и
  полностью повторяет результат по seed. Проверены 192 генерации по всем 12
  уникальным случайным ruleset кампании, всего 952 размещённых chunk.
- Восстановленный PRNG и взвешенный выбор проверены 44 000 прямыми сравнениями
  с машинным кодом оригинала. Ещё 20 004 сравнения подтверждают точную
  геометрию пересечения chunks, включая необычное поведение исходной функции.
- Четыре примитива `CAstarPathfinder` проверены ещё 104 000 прямыми вызовами
  машинного кода. A* использует исходную цену шага, квадратичную эвристику,
  радиус поиска открытой клетки 16 и лимит раскрытия 150 узлов.
- Переносимый загрузчик оригинальных OGRE `MeshSerializer_v1.40`: проверены
  все 3 312 моделей, 1 939 624 вершины, 2 461 269 индексов и 5 105 submesh.
  У всех 3 528 геометрий извлечены основные UV-координаты. Для города разрешены
  все 303 уникальные модели деталей окружения.
- Каталог 1 182 OGRE material-скриптов с 2 749 определениями. Все 525 материалов
  городской сцены найдены и связаны с исходными текстурами.
- Переносимый декодер DDS в RGBA8 обработал все 2 776 текстур: DXT1, DXT3,
  DXT5 и несжатые RGB24/RGBA32, всего 231 484 880 пикселей верхнего mip-уровня.
- PNG-декодер обработал все 188 PNG из архива, включая текстуры моделей
  персонажей, всего 11 607 552 пикселя.
- Первый исполняемый этап `torchlight_bootstrap`, доходящий до
  `town-meshes-ready`.
- Нативное окно Wayland/EGL/OpenGL ES 2 с корректным полнооконным viewport и
  обработкой изменения размера. Оно рисует все 352 детали города, 44
  размещённых NPC и Алхимика: 397 экземпляров, 560 пакетов, 212 965
  треугольников и 130 уникальных исходных текстур. Этот рендер-путь близок к
  Android GLES по API.
- Тем же путём уже рисуется собранный этаж шахт с Алхимиком в исходной точке
  `PlayerStart`: для seed 42 это 3 chunk, 2 866 экземпляров, 171 159
  треугольников и 46 исходных текстур. Загружены прототипы всех трёх игровых
  классов с их GUID, характеристиками, скоростями и моделями.
- Интерактивный ПК-прототип центрирует камеру на Алхимике, преобразует левый
  клик в координаты пола и двигает модель с исходной скоростью бега по A*.
  Первый этаж даёт сетку `178x171` с 3 673 проходимыми клетками; реальный клик
  в окне Wayland проверен сквозным запуском.
- Загружены все 623 присутствующие уникальные collision mesh из 858 ссылок
  levelset. Для контрольного этажа 2 232 экземпляра объединены в 18 041
  треугольник пола и препятствий. Повороты layout теперь одинаково применяются
  к графической и collision-геометрии.
- Воспроизводимый разбор интерфейса: 35 `.layout`, 1298 элементов,
  115 объявлений событий, 97 записей таблицы команд.
- Исследован официальный TorchED SDK: его родной `Core.dll` экспортирует 193
  функции и содержит RTTI 302 классов движка, имена которых присутствуют в
  Linux-бинарнике. Из .NET-оболочки восстановлены 196 P/Invoke-сигнатур с
  типами и именами параметров; 4 758 IL-методов дали карту 423 прямых вызовов
  родного движка.

Это начальный участок восстановления. Освещение, сглаживание пути,
динамические физические коллизии, скелетная анимация, звук, бой, Android APK и
сенсорный интерфейс пока не реализованы. Библиотека собрана и проверена на
Linux x86-64; сборка ARM64 ещё не проверена.

## Сборка и сравнение с оригиналом

Для текущей установки весь цикл запускается одной командой:

```sh
./tools/check.sh
```

Если игра лежит в другом месте, передайте каталог `game` аргументом:

```sh
./tools/check.sh /путь/к/Torchlight/game
```

Нужны CMake, компилятор C++17, Python 3, libpng и GNU binutils (`nm`,
`objdump`). Ninja используется в примере; сторонних Python-пакетов не
требуется.

```sh
cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=RelWithDebInfo \
  -DTORCHLIGHT_ORIGINAL=/home/qweasd123tg/Документы/Torchlight/game/Torchlight.bin.x86_64
cmake --build build
ctest --test-dir build --output-on-failure -V
```

После сборки запуск восстановленного этапа загрузки данных:

```sh
./build/torchlight_bootstrap /home/qweasd123tg/Документы/Torchlight/game
```

Текстурированная геометрия города:

```sh
./build/torchlight_desktop /home/qweasd123tg/Документы/Torchlight/game
```

Сгенерированный первый этаж шахт с указанным seed:

```sh
./build/torchlight_desktop /home/qweasd123tg/Документы/Torchlight/game \
  --main-stratum 0 --seed 42
```

Окно закрывается клавишей Escape или штатной кнопкой закрытия.

Тест запускает в отдельном процессе только проверенные функции оригинала.
Оригинальная игра, видимое окно и сохранения в тесте не запускаются; GLES
проверяется в невидимом буфере. Для единственного внешнего вызова
`SDL_GetKeyboardState` тест предоставляет управляемый массив состояния клавиш.
Код переходов состояния оригинала исполняется без изменений.

Тест поддерживает строго одну исследованную сборку и Linux x86-64 с размером
страницы 4096 байт. Другой SHA-256 отклоняется. Оригинальный бинарник нужен
локально и не включается в библиотеку. При сборке без `TORCHLIGHT_ORIGINAL`
сравнение не подключается; отсутствие такого теста не подтверждает совместимость.

## Повторить исследование интерфейса

```sh
python3 tools/audit_original.py \
  --game-dir /home/qweasd123tg/Документы/Torchlight/game
```
