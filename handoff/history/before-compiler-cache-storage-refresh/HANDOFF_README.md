# Полный текущий снимок OpenTorchlight

Полное дерево проекта и накопленные находки на 10 октября 2026 года: исходники, заголовки, third_party, инструменты, тесты и research/. Эта отдельная ветка передачи включает проверенные рабочие ветки; их наличие здесь не означает слияние draft PR в main.

## Текущая проверенная база

411 общих headless-тестов прошли в изолированной сборке и повторно в корне проекта. Принято 2348 из 5247 игровых адресов: 2116 MATCH и 232 по выполненным сравнениям поведения. Проверенный коммит main после интеграции gameui-event-callbacks: 572a343509f505a4204b18d36c7329e7540011d8.

Все 3 файлов из проверенного интеграционного манифеста gameui-event-callbacks перенесены из этого коммита main с проверкой SHA256. Подробнее: research/gameui-event-callbacks-2026-10-10.md. Прежние исследования, фрагменты и метаданные происхождения сохранены. Предыдущие версии текущего индекса, сводки и README сохранены в handoff/history/before-gameui-event-callbacks-refresh/.

Все 401 определения из накопительного снимка ChatGPT Pro интегрированы в обычные decomp/src и decomp/include. Свежая проверка первичных определений: 396 MATCH и пять поведенческих сравнений. Проверены также испускаемые ABI-варианты. Заголовки восстановлены и согласованы с остальным кодом; подробности в research/pro-401-integration-2026-10-10.md.

handoff/recovered-pass10/ сохраняет исходные фрагменты и исторический индекс без потери данных. Его старые метки описывают прежний снимок; актуальная приёмка находится в текущей базе и handoff/ALL_FUNCTIONS/index.json и перечисленных там CSV-частях. Не начинать эти 401 определения заново.

## Перед выбором следующей функции

Сначала читать handoff/ALL_FUNCTIONS/index.json и перечисленных там CSV-частях: общий индекс 7663 адресов, включая принятую базу, библиотечные MATCH вне игрового счётчика и существующие DIFF. Затем сверять исходник, оригинальный ELF и decomp/owners.json. SMALL_FUNCTIONS.csv является исторической подсказкой, не актуальной очередью.

getTextEventObject (0xa9ba60) теперь принята и включена в decomp/src/gameui.cpp: 6144 нормальных сравнения, 160 отдельно проверенных исключений и восемь отрицательных контролей. Старый кандидат handoff/in-progress/ оставлен только для истории; повторять его работу не нужно. Подробности в research/gameui-text-event-2026-10-10.md. Сохранять все прежние исследования; не переписывать уже имеющиеся реализации с нуля.

## Компилятор и оригинальная игра

Закреплённый GCC 4.4.7 находится в ранее переданном архиве в чате. Бинарный архив компилятора в эту ветку не загружен. После его распаковки использовать handoff/env.sh и инструкции AGENTS.md. Оригинальный ELF, игровой runtime и ресурсы в Git не публикуются; нужен внешний вход из собственной копии игры или ранее переданного комплекта.

SHA256 оригинального ELF: 91b41ae9dfea30aab6bc14dbbfcceaee096d600f39635b8507f5a88b5d41724b.

Принятые функции и headless-тесты ещё не доказывают самостоятельную сборку или играбельность всего проекта. Оконный запуск выполнять только по отдельной просьбе пользователя.

Индекс разделён на небольшие CSV-файлы с одинаковыми заголовками. Вместе они содержат все 7663 адресов без повторов и сокращения имён. index.json перечисляет части, количество строк и SHA256. Прежний индекс handoff/SMALL_FUNCTIONS.csv сохранён без изменений только для истории.
