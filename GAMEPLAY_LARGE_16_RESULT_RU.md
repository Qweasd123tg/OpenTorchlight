# OpenTorchlight large-16 — результат прохода

## Что поставляется

Рабочая база — точный пользовательский `OpenTorchlight-gpt-pro-large-15.zip`.
Large-16 включает её код и предыдущие UI-исправления. Новый полный ZIP — исходный
проект, не готовый установщик полной игры. Рядом поставляется единый патч к
large-15 и комплект с полными изменёнными файлами, безопасным установщиком,
картой файлов и точными исходными/итоговыми строками.

Pak, ELF и оригинальные библиотеки/шрифты не включены. Новая `.otc` в тестах —
созданный неизменённым портом контрольный файл, не оригинальный SVB.

## Что действительно реализовано

**Обычный прямой оружейный урон по типам.** Базовый графовый бросок распределяется
по исходным процентам. Сохраняются порядок float-операций, усечение и отсутствие
нормализации до 100%. Базовый физический удар и добавочные каналы не сливаются
перед защитой: оригинал обрабатывает их отдельно, с разными знаменателями и
случайными вызовами. MAGIC участвует в исходной бонусной ветви. Итог применяется
на событии HIT один раз через существующие HP/смерть/XP.

**Возвращена обычная атака стартового посоха алхимика.** Настоящий Moldy Staff
задаёт PHYSICAL=0, POISON=100. Теперь это яд с соответствующим вкладом MAGIC и
защитой цели, а не прежняя физическая замена. Метки MISSILE/оружейного SKILLS не
превращаются в мгновенное попадание. Критические, блокирующие и скользящие удары,
procs и полный магический бой этим проходом не реализованы.

**Защита по каналам подключена к обеим сторонам боя.** Пересчёт экипировки/DEF
обновляет физическую и поддержанную элементальную защиту игрока; атака игрока
читает соответствующие параметры монстра. Ошибка не оставляет частично
обновлённое состояние. Сохранены анимация, HIT-дедупликация, дальность и
поддержанная проверка препятствий. Источники эффектов остаются ограничены
реально реализованными загрузчиками — полный генератор аффиксов не заявляется.

**Уточнена прежняя трактовка Infuse.** В настоящем аффиксе указаны бонусы
ближнего/дальнего урона с DAMAGE_TYPE=ALL, а не физического типа. Поэтому
новая бонусная оружейная ветвь тоже их использует. Старый положительный сценарий
обучения, применения и истечения не ослаблен и проходит.

## Какие ошибочные ожидания устранены

Тесты оборудования и предметного цикла требовали физический бросок у настоящего
ядовитого Moldy Staff. Они заменены проверками исходного распределения,
сохранённого броска и RNG. Новые положительные тесты прямого смешанного урона не
отменяют отрицательные тесты MISSILE/SKILLS. В миграционном тесте ASan обнаружил
висячую ссылку после повторной гидратации контейнера: тест теперь хранит копию,
повторный прогон ASan/UBSan чистый. Промежуточные неудачи не считаются успехами.

## Сохранения

Формат **OTC v6**, чтение v1–v5 сохранено. Старый графовый бросок используется
для однократного восстановления недостающих каналов по исходному GUID, без
нового RNG, смены текущего HP/маны/кошелька/опыта и без повторного лечения.

Миграционный файл получен неизменённой large-15 через настоящее меню. Два новых
процесса выполняют v5→v6→v6: исходный бросок 23 становится poison=23, physical=0,
MAGIC=10, RNG=491; повторный v6 каноничен побайтово. Протокол и происхождение:
`verification/large-16/typed-migration.json` и `tests/fixtures/typed-v5-player.json`.
Это не оригинальный формат SVB.

**Перед переходом сохранить отдельные копии своих `.otc`: large-15 не читает v6.**

## Проверки

| Набор | Пройдено | Неудачи / пропуски |
|---|---:|---:|
| Ядро и игровые состояния | 67 | 0 / 0 |
| Настоящие ресурсы | 41 | 0 / 0 |
| Сравнения с оригинальными инструкциями | 16 | 0 / 0 |
| Mesa/EGL: отрисовка и общий игровой цикл | 8 | 0 / 0 |
| Выбранные ASan/UBSan, отдельная сборка | 14 | 0 / 0 |
| Выбранные Release, отдельная сборка | 5 | 0 / 0 |

Основной набор содержит **130 уникальных тестов**: две проверки имеют метки
core и render одновременно. ASan/UBSan и Release пересекаются с основным набором;
их числа не прибавляются к 130. До правок неизменённая large-15 прошла 66 core.
Release собран с действующими предупреждениями как ошибками, без их отключения.

Новый независимый стенд сравнил **12 088 случаев** с исполнением оригинальных
инструкций: 3088 распределений, 1500 MAGIC, 1500 наборов защиты и 6000 обычных
атак. Совпадают проверяемые значения, порядок каналов и RNG. Повторение тех же
случаев в Release не удваивает число. Граница перехвата до block/glancing/procs
и исходного применения HP; эффекты и часть объектов задаются контролируемыми
входами. Это не доказательство равенства всей функции или всей игры.

Сквозной тест на настоящем pak выполнил **44 проверки в двух процессах**:
создание алхимика → город → Main 1 → выбор и убийство противника стартовым
посохом → XP → save → continue. Зафиксированы 52 сущности, один player-HIT kill,
XP=100. Оружие, враги, HP, уровень и опыт не внедрялись фикстурой. Противники
используют текущую ещё неполную модель размещения; совпадение их расположения
с оригиналом этим сценарием не доказано.

Не запускались нативное Wayland-окно, ветвь с настоящим FreeType SDK, исходная
CEGUI для сравнения кадров и полная кампания. Headless Mesa проверяет реальную
отрисовку порта, не пиксельное совпадение с оригинальной игрой.

## Что дальше и где доказательства

Снаряды/оружейные умения и расширение цепочки попадания; исходные требования и
полная модель секций/слотов инвентаря; масштабирование, пауза сторон и анимированный
UI; затем услуги, питомец, цели/награды заданий, боссы и связная кампания. В этом
проходе требования к экипировке только изучены до исходной цепочки функций —
не реализованы. Ни число поддержанных определений, ни число тестов не являются
процентом готовности игры.

`research/large-16-typed-damage.md` содержит адреса, точные границы вывода и
воспроизведение native-стенда. `NEXT_PATCHES_LARGE_16_RU.md` — следующие патчи
с функциями оригинала и критериями приёмки. `verification/large-16/` содержит
JSON и журналы CTest/ASan/Release. Отдельный комплект патчей содержит точные
строки и полный код каждой замены. Новые исходные игровые файлы не требуются.
